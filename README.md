# Ο προσωπικός μου χώρος AI

Greek workshop guide for school teachers. Includes the six-stage Personal AI Workspace Builder, copyable instructions, a downloadable skill, sample data and a browser-local progress checklist.

## Publish with GitHub Pages

In Settings → Pages, choose Deploy from a branch, then main and / (root), and Save.

Expected address after publication: https://courseg.github.io/ai-workspace-teachers/

The site is self-contained in index.html. No build step is required.
